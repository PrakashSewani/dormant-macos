# Coding

- Expects visual polish and consistency across every section of a page — flags "out of place" or
  unstyled blocks (e.g. an unstyled footer breaking out of the page container) and wants the
  irregularities fixed and re-verified in the browser, not just described. Confidence: 0.7
- Brand/visual marks should be witty and conceptual over literal — "ditch the moon design lets come up with something witty"; rejected a literal crescent for a pun-driven mark (cocoon = "hatches exactly when you need it") and values the mark carrying the product's joke/promise. Confidence: 0.75
- Context-sensitive menus: right-click actions must be scoped to what is valid for the exact click target — folder-item clicks get only folder actions, empty-space (container) clicks get only container actions ("when i right click a folder inside dormant dont show open in dormant, when i right click inside a folder in empty space in dormant, add open directory"). No catch-all menus carrying irrelevant items. Confidence: 0.75
- Prefers explicit, user-chosen organization over automatic inference in app data models: confirmed that only explicitly imported folders become tracked "directories" (Work vs Personal project roots) and rejected auto-grouping projects by parent folder. Confidence: 0.6
- Wants size/usage reporting to show the real on-disk footprint of a folder (whole subtree — projects, dependencies, build output, untracked files), not a sum of tracked items only — "show at directory level how much each directory space is being eaten". Confidence: 0.65
- Prefers hardcoded behavior over user-configurable settings in his apps, and hard errors over silent fallbacks — "don't ask for custom path from user": tool paths come from a fixed lookup list, a missing tool throws (exit 127 with the searched directories listed) and stops later commands, and he had the editor-command setting + its Settings UI deleted in favor of a fixed `code .` with an error alert when missing (explicitly "no Finder fallback"). Applies to app design generally: less configuration surface, loud failures. Confidence: 0.8
